# flush-signal

A hand-rolled `Future` (`FlushSignal`) representing "has a background audit-log flush finished," driven by a from-scratch, no-runtime-dependency `block_on` — plus a deliberately broken sibling (`BrokenFlushSignal`) that never wakes its executor.

`FlushSignal` holds an `Arc<AtomicBool>` completion flag, a `started` guard, and a `Duration` standing in for real flush I/O. The first `poll` spawns a background thread that sleeps for that duration, sets the flag with `Release`, and clones and wakes the `Waker` pulled out of `Context` — the flag check in `poll` reads it back with `Acquire`, the standard publish/consume pairing. `block_on` is a from-scratch executor: a `ThreadWaker` wrapping `thread::current()`, turned into a real `Waker` via the safe `std::task::Wake` trait, driving a `poll`/`thread::park` loop that's genuinely idle between polls, not spin-polling.

Verified via three tests: `waits_the_full_duration_before_resolving` (`block_on` genuinely blocks for the real duration rather than returning early); `polls_exactly_twice_not_spin_polled` (`block_on` returns a `(T, poll_count)` pair, confirming exactly one `Pending` and one `Ready` call — not thousands from a busy loop); and `broken_future_hangs_forever_without_a_waker`, which proves `BrokenFlushSignal` — identical to `FlushSignal` except its spawned thread never touches a `Waker` — hangs its driving thread forever, via a bounded `mpsc::recv_timeout` watchdog racing a `block_on` call running on its own thread, never an unguarded wait.

The lesson `BrokenFlushSignal` exists to prove: returning `Poll::Pending` isn't just "not ready yet" — it's an obligation to clone the `Waker` you were handed and call `.wake()` on it once progress becomes possible. Nothing in the type system enforces this. `BrokenFlushSignal`'s background thread does its real work and sets its flag correctly, but because nothing ever calls `.wake()`, the executor — having parked itself waiting for a wakeup that will never arrive — never finds out. No panic, no error, just a task that hangs forever, which is exactly what the bounded watchdog test demonstrates directly rather than asserting in the abstract.
